## S1 Asset lifecycle

- `add_canvas_asset` 仅接收当前 DSH Workspace 内的 PNG/JPEG/GIF/WebP；拒绝
  URL、越界路径、symlink、hardlink 和无效图片头。
- 单资源上限 1 MiB，解码后资源总量上限 2 MiB，宽高均不超过 8192，像素总量
  不超过 32 MiPixels；最终文档继续受 canonical 4 MiB 上限保护。
- 内容 SHA-256 同时作为稳定 `assetId` 和返回 hash；结果包含 canonical
  `canvasPath`、MIME、宽高、字节数和 revision。
- `remove_unused_assets` 只删除未被任何 live image element 引用的文件。
- 两项变更都复用 ProjectStore mutation registry、串行队列和 CanvasStore 单次
  CAS atomic write；精确重试返回首个结果。

## S2 Export lifecycle

- JSON 使用官方 serializer；SVG/PNG 只在 Browser View 中调用固定版本
  Excalidraw `exportToSvg` / `exportToBlob`，再交给 Host 下载。
- JSON/SVG/PNG 下载只由用户点击 View 中的对应按钮触发，并使用
  canvas-derived filename。
- Server 不暴露 `export_canvas`；保存、模型工具结果和 Harness 捕获不会触发下载。
